Inventario Service

API REST académica desarrollada con Jakarta EE 11, WildFly 41, Java 21 y SQL Server.

Productos

  • GET /api/inventario/productos — Listar productos.
  • GET /api/inventario/productos/{id} — Consultar un producto por ID.
  • GET /api/inventario/productos/codigo/{codigo} — Consultar por código.

Consulta de stock

  • GET /api/inventario/productos/{id}/stock — Consultar stock por ID.
  • GET /api/inventario/productos/codigo/{codigo}/stock — Consultar stock por código.

Operaciones de inventario

  • POST /api/inventario/productos/{id}/reservas — Reservar stock por ID.
  • POST /api/inventario/productos/{id}/devoluciones — Devolver stock por ID.
  • POST /api/inventario/productos/codigo/{codigo}/reservas — Reservar stock por código.
  • POST /api/inventario/productos/codigo/{codigo}/devoluciones — Devolver stock por código.
Pruebas de la API: utiliza el archivo requests/inventario-service.http para enviar solicitudes y comprobar las respuestas.
